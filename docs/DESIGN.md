# 設計

## 方針

- 無料のデータ経路のみを使う。対象は Wolfx と P2P地震情報であり、どちらも可用性・品質の保証はない。この制約を前提に、破壊的な動作ほど強い証拠を要求する段階的な発動ポリシーを取る。
- 依存は Python 3 標準ライブラリのみ。WebSocket クライアントと RCON クライアントは自前実装であり、導入先で追加インストールを要求しない。HTTP(S) プロキシ環境変数（http_proxy / https_proxy / no_proxy）は標準の作法どおり尊重する。
- 秘密情報とインフラ固有値（ホスト座標、地域名、Webhook URL、RCON パスワード）は設定ファイルと環境変数に置き、リポジトリには含めない。

## 経路の性質（検証済み）

| 経路 | 内容 | 公称・実測 |
|---|---|---|
| Wolfx `jma_eew` | 予報と警報の双方、取消は `isCancel` | 非公式の再配信。公式警報の代替として使用しない旨が自己規定されている。heartbeat は接続時＋60秒間隔 |
| P2P code 556 | 警報のみ（予報は配信されない） | 公式仕様書が「無保証」「緊急地震速報（警報）としての利活用は非推奨」「冗長化しておらず障害時は配信できず、復旧時の再配信もない」と明記 |
| P2P code 554 | EEW 発表の検出のみ（震源情報なし） | 照合専用に使う |
| P2P code 551 | 地震情報（実測震度） | Tier 2 の確認に使う |

600秒の実測（2026-11-09）で両経路とも接続維持を確認した。観測時間内に EEW 発表がなかったため、EEW 実電文の到達遅延は未実測である。

## 発動ポリシー

ホスト所在地の予測震度は、経路が持つ地域別予報（Wolfx WarnArea、P2P areas）への一致を第一とし、一致しない場合のみ減衰推定（司・翠川式に基づく近似）にフォールバックする。減衰推定は気象庁の地域別予報より低く出る較正限界があるため、通知と保存開始にのみ使い、ログイン停止には使わない。

| 動作 | 条件 |
|---|---|
| Tier 0 通知＋記録 | 予測震度 震度4以上（単独経路で可） |
| Tier 1 保存開始（RCON `save-all flush`） | 同上 |
| Tier 1 ログイン停止 | 地域別の予測震度 5弱以上、かつ照合成立。照合は「P2P 556 の受信」または「Wolfx 警報＋120秒以内の P2P 554 検出」。Wolfx 単独では発動しない |
| Tier 2 停止推奨＋再起動抑制フラグ | 地震情報（551）でホスト地域の実測震度 5強以上が対象イベントと一致した場合（地域データが無い場合のみ全国最大で代替）。サーバー停止の自動実行は設定 `allow_server_stop` が有効な場合のみ |
| 取消 | ログイン停止中で停止未実行なら、ログイン停止のみ解除する。停止後は自動再起動しない |

ログイン停止・再開のサーバーコマンドは運用側のゲート方式に依存するため、設定でコマンド列として与える（未設定なら状態追跡と通知のみ）。

サーバーへのコマンド実行は2方式から選べる。ローカルコマンド（argv 配列、シェルを介さない。例：コンテナ内の RCON クライアントを `docker exec` で叩く）は RCON より優先され、RCON（Source RCON プロトコル、標準ライブラリ実装）はサーバーが直接到達可能な配置で使う。

## 取消の時間尺度

2026-10-16 の事例では警報発表からキャンセル報まで約8分48秒を要した。取消到達前に保存や停止が完了しうるため、設計は「取消で原状回復できる」前提に置かない。複数経路はいずれも同一の気象庁電文の再配信であり、電文自体の誤りは照合では検出できない。

## heartbeat

agent は60秒間隔で heartbeat ファイル（epoch 付き JSON）を原子的に更新する。watcher は180秒の途絶で障害通知、復旧で復旧通知を送る。heartbeat の搬送（共有ファイル、HTTP、オブジェクトストレージ）は配置側の選択であり、形式のみを本設計で定める。

## 既知の限界

- EEW 実電文の到達遅延は未実測であり、次回の警報級 EEW 時の受動観測が検証手段になる。
- 減衰推定は近似であり、地域別予報が得られる範囲では使われない。
- 無料経路の同時障害は検出できる（heartbeat と経路死活）が、代替経路は存在しない。
- バックアップ暗号化・保全と復旧手順の自動化は本増分の対象外であり、共通基盤として別途実装する。
